# Global instructions

**Authority: current, and short-lived.** There is nothing to apply by hand any more. From v7 the
installer copies `install/global.md` to `~/.claude/CLAUDE.md` and `$CODEX_HOME/AGENTS.md`, backing
up a file that differs to `<name>.bak-<YYYYmmdd-HHMMSS>` beside it, and `./install.sh --uninstall`
puts the newest backup back. See [install/README.md](../../install/README.md). The v6 replacement
text this page used to carry is in git history; T8 of goal S-1 removes this page.
